# Enjoy Player v0.10.3

A patch release that ships the Windows and Android builds again, makes the
signed-in start and the transcript noticeably faster, re-fetches the
recordings a failed sync page used to strand, keeps a single-platform
publish from wiping the other platform's self-update, brings the macOS
build back to macOS 12–15, and loads YouTube captions behind system-proxy
VPNs again.

## Captions work behind a system-proxy VPN again

Dart's HTTP stack resolved proxies from environment variables only, so on
macOS and Windows desktop the OS-level system proxy was invisible to it:
behind a Clash or sing-box system-proxy VPN the video played but captions,
oEmbed metadata, and remote thumbnails connected directly and failed at the
transport level.

Dart HTTP now follows the OS proxy on desktop — re-read every 60 s, the
exception list honored, loopback always direct — and a new **Settings →
Network** section shows the resolved mode (system / manual / direct), the
effective proxy endpoint and source, and a connection test against the
Enjoy API and YouTube (#1220, #1227).

## The macOS build launches again on macOS 12–15

The direct-download macOS app shipped the libraries next to its bundled
FFmpeg copied straight out of the build machine's Homebrew installation.
Homebrew's bottles are built for the current macOS, so every one of them —
fontconfig, freetype, zlib, harfbuzz, glib and the rest of the closure —
reported "built for macOS 26.0", and the freetype bottle additionally linked
a system library that exists only on macOS 26. dyld therefore killed the app
before it drew a window on any older macOS.

Those libraries are now built from pinned sources against the app's macOS 12
minimum, and two new build gates reject any bundled library that would not
load on macOS 12 — so the next Homebrew release fails the build instead of
the user's launch (#1189).

## Windows and Android ship again

The v0.10.2 tag produced the macOS and Linux artifacts but failed its Windows
and Android release jobs: both runners run the full test suite, and five cases
failed there for platform reasons rather than product ones — two design guards
compared raw paths with `/` separators, so their Windows exemptions never
matched; one media-analysis case expected a POSIX path back from
`Uri.toFilePath()`; the pre-v6 migration guard left the failing database open,
so Windows could not delete its temp directory; and the expanded-player
thumbnail test read an autoDispose provider without a listener, so it could be
disposed between reads.

All five now pass on their own runners, so this release carries the Windows
installer and the Android bundle and sideload APKs (#1123).

## Faster signed-in start

Resolving the locale, the learning language, the native language and the theme
mode happens before the app renders its router, so those four reads sit on the
signed-in cold-start critical path. They were four separate queries against the
settings table; they are now one query, with each value still resolved through
its own codec and still falling back to its declared default (#1124).

## Faster transcript

The familiar-form IPA was derived from scratch every time it was asked for —
once per word of a row on every row rebuild, once more per word for the "does
this row have phones" boolean, and once per line across the whole transcript
while the transcript scans for display readiness. The derivation is now
memoized per word, and the readiness scan stops as soon as its flags are known
(#1127).

## Failed sync pages are re-fetched

The lazy recording pull advanced its per-target cursor past every row of a
page whose merge reported failures, so the recordings in a poisoned page were
never re-fetched. The cursor now advances only when every row in the page
applied cleanly, and a failed page stops the pull so the next media-open
re-fetches the same window — the download path's cursor invariant, now held by
the lazy pull too (#1178).

## A single-platform publish keeps the other platform's self-update

Publishing one platform used to rewrite the Sparkle `appcast.xml` with only
that platform's item, so the other platform's installed clients got an empty
feed and no self-update. The feed merge now unions: the published version wins
for the platform it carries, and an unshipped platform keeps its item and
signature (#1145). The publish pipeline also refuses to ship an update users
cannot consume: a GitHub Release without every platform's asset is not
published, draft releases verify their assets against the built artifacts, and
the two update feeds are checked to agree before either is uploaded
(#1138, #1141, #1146).

## Also in this release

- The five hand-rolled yes/no confirmations (credits purchase, subscription
  cancel, product-tips reset, vocabulary delete, recovery-library reset) go
  through the shared confirm dialog, and the vocabulary delete gains the
  destructive styling (#1165).
- The five save/share hand-off flows (diagnostics zip, transcript download,
  Anki CSV export, practice poster, loop-clip export) share one
  implementation: a dismissed share sheet is a silent cancel everywhere, and
  desktop saves pass an explicit mime type (#1161).
- The transcript, the ASR timeline build, and the pitch-contour chart do less
  work per frame: recording-overlap counting drops its nested scan, plain cue
  text and the blur cue id are derived once per row and line, the
  auto-translate source key is memoized, unchanged echo-card tiles are reused
  across rebuilds, the pitch-contour painter derives its voiced runs once per
  series, and the ASR timeline build no longer re-joins the current line on
  every step (#1142, #1167, #1175, #1191, #1203, #1218, #1228).
- Internal consolidations with no user-visible change: the cloud library tabs,
  the recording elapsed ticker, and the async error state each collapse to one
  implementation, with `ErrorState` beside `EmptyState` as the canonical error
  presentation (#1201); the hotkey listing, the lookup callouts, and the
  theme-token wiring each collapse to one implementation (#1217); sync paging,
  purchase-error mapping, and the local import flow share one home each
  (#1226); and further dedup and split passes cover the hotkey letter-key
  table, the status pills, the Developer-section editors, the filter pills,
  the alignment pipeline, the ApiClient response envelope, the player dock,
  the shadow-reading panel, and the theme file (#1180, #1181, #1185, #1186,
  #1188, #1196, #1208).
- The dependency set moves forward within the constraints the project already
  set — no dependency is added, removed or given a wider constraint
  (#1125, #1215).
- The eSpeak-NG synthesizer in the forced-alignment package splits into five
  focused modules, with no change to its public API or its behavior (#1135).
- The 2026-10-28 documentation review findings are resolved, and a design
  guard now rejects Material's `SegmentedButton` in `lib/` (#1130, #1131,
  #1133).
