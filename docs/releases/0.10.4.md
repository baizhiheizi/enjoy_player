# Enjoy Player v0.10.4

A feature release that adds dictation practice under the Dictate lens,
keeps craft text edits safe from unrelated state updates, teaches the
craft history subtitle to follow the app's display language, makes date
rendering up to ~26x cheaper, and repairs echo pronunciation underlines
on video and non-English media.

## Dictation practice: listen, then prove it

The Dictate lens is now a full practice loop, not just hide-and-peek. The
looped line's words stay masked while you listen, then you prove you
understood them in one of two ways:

- **Voice retell** — record with `R`; your take is transcribed and every
  word is compared against the original.
- **Text** — type what you hear, with a live word-count progress line.

After checking, the line reveals an inline word-level diff — correct,
missed, or extra — plus an accuracy percentage. Try again resets the
attempt, Next line moves on, and every checked attempt is kept under
"Previous dictations" for the line. Voice retells persist as regular
shadow-reading takes, so they replay and score exactly like echo takes,
and entering Dictate arms a one-line loop on the active cue — the loop is
what hosts the practice card (#1308).

On touch screens, press-and-hold now peeks a masked line (on plain tiles,
grouped-echo tiles, and the dictation band itself), and the Dictation
panel's hints split by platform so phones no longer see desktop hotkey
copy (#1352).

## Vocabulary sync you can drive

- **Re-pull vocabulary** — a new button on Settings → Sync status resets
  both vocabulary sync cursors and pulls the full server word book, so a
  drifted word book can be rebuilt on demand without touching remote
  media (#1348).
- **Upgrades repair the old backlog once more** — installs upgraded from
  v0.10.0–v0.10.3 re-pull the word book one more time, recovering web SRS
  updates the server's old pagination had stranded (#1348).
- **Words added on web reach the phone without a cold restart** — the
  periodic sync now runs the full pull, and the Vocabulary board gains
  pull-to-refresh (plus a header refresh button on desktop).

## Echo pronunciation underlines, restored

The pronunciation wavy-underlines silently disappeared on video and on
non-English media: the scored-take lookup hardcoded `Audio`/`en` while
takes persist under the media's real target type and language. The lookup
now derives from the same region record the chrome uses, and the
recording surfaces share one elapsed-time caption (#1323).

## Craft text fields keep in-progress edits

The Advanced and Express craft text fields could lose the draft and
cursor when an unrelated state update landed mid-edit. External updates
now wait until the field loses focus instead of replacing the text under
the user, and explicit actions (Re-translate, Regenerate, Use translated
text) release focus so their new value appears immediately — even on
touch devices (#1294).

## Faster date labels, in your language

The craft history tiles and the library's relative-day labels built a
fresh date formatter on every row rebuild. Each formatter is now built
once and cached, with identical output: a 502-row pass drops from
3.0–4.6 ms to 0.13–0.17 ms (~26x) on the craft path, and from
0.70–0.76 ms to 0.075–0.13 ms (~6x) on the relative-day path (#1299).
The same per-locale cache now serves the credits usage tables, the sync
stamp, the home date overline (#1310) and the subscription status card
(#1412), and the craft history subtitle — which was silently hardcoded
to English date formatting — now follows the app's display language like
the surfaces beside it (#1419). Craft's rebuild gates stop
re-normalizing the whole transcript per keystroke: typing states drop
from 9.85 ms to 0.41 ms and a 5 000-character text from 2 792 ms to
1.08 ms (#1403).

## The lookup credits header stops over-fetching

Every loaded-section rebuild of the lookup sheet invalidated the credits
summary unconditionally, so one display plus five same-result rebuilds
fired seven live balance calls for a number that had not moved. The
refresh is now deduped per section by the result token: a same-result
rebuild refreshes nothing, a fresh result refreshes exactly once
(7 fetches → 2) (#1258).

## Also in this release

- Build reliability: all four platform build workflows retry `flutter pub
  get` with pub.dev when the China mirror serves a stale archive, the
  sqlite3 native-library prefetch survives a 504 from GitHub's release CDN
  with an API-endpoint fallback, and the Drift-backed tests carry a
  five-minute budget on shared runners (#1269).
- A broad performance pass with measured, output-identical results: ASR
  streams audio from disk instead of materializing ~500 MB of PCM
  (#1388), heavy I/O and parsing move off the UI isolate while sync drains
  in parallel (#1387), SQLite gains two missing indexes and reactive
  streams narrow to what their listeners read (#1386), transcript rebuilds
  isolate karaoke from chrome (#1385), the player surface stops
  rebuilding on karaoke ticks (#1384), logo covers drop their saveLayer
  passes (#1382), the signed-in cold start skips redundant writes
  (#1381), card thumbnails derive once per content (#1389), and
  vocabulary explanation blobs decode once per content (#1364).
- Internal consolidations with no user-visible change: the transcript
  track writes, the lookup sections, and the vocabulary flashcard state
  each collapse to one home (#1402); the echo-activation flows collapse
  into one owner (#1349); the recording elapsed readouts share one
  timebase (#1334); transcript row construction is named once (#1334);
  one microphone-capture session serves both recorders, so Craft now
  honors your microphone choice (#1369); the dictation, transcript tile,
  auto-translate, transcript-enrich, AI playground, echo card, caption
  fetcher, and cloud library screens split into focused modules
  (#1366, #1284, #1295, #1357, #1350, #1316, #1397, #1302); the dock
  readout stops rebuilding on karaoke word ticks and gains its first
  widget tests (#1393); and the 2026-11-15 audit batch resolves five
  duplicate-code findings (#1379).
- CI splits into four sharded test legs with a host lane budget, so two
  overlapping runs can no longer drive the shared runner into swap
  (#1335), and the local git hooks stop blocking legitimate commits
  (ADR-0104).
- The dependency set moves forward within the existing constraints —
  drift 2.35.4, sqlite3 3.9.1, record 7.2.0 and companions; no constraint
  is widened and nothing is added or removed (#1269, #1373).
- Documentation: the dictation feature page ships, the 2026-11-11 and
  2026-11-18 docs-drift review findings are resolved, and the CHANGELOG
  gains the entries its window shipped without (#1308, #1313, #1413,
  #1268).
