# Enjoy Player v0.11.0

A minor release that adds full dictation practice under the Dictate lens,
brings one-click checkout returns, real sign-out revocation and an account
switcher to the native auth flow, lets a drifted word book be rebuilt on
demand, syncs words across devices without a cold restart, wires the
hold-to-peek gesture phones were promised, and makes nearly every surface —
cold start, transcript, player, vocabulary, sync — measurably cheaper to
render. The toolchain also moves to Flutter 3.50.1 / Dart 3.14.0.

## Dictation practice under the Dictate lens

The Dictate lens grew from hide-and-peek into a full listen-and-prove
practice loop with two answer modes. **Voice retell** records with `R`
through the shared shadow-reading recorder: the take transcribes through
ASR and diffs word-by-word against the loop's reference text, with a
"No speech detected" retry when the microphone heard nothing and retell
takes persisting as regular shadow-reading takes. **Text** is
type-what-you-hear with a live "{typed} of about {total} words" progress
line and a Check answer action.

After checking, the masked reference words reveal an inline word-level
diff — Correct / Missed / Extra legend plus per-attempt accuracy — with
Try again to reset and Next line to advance. Every checked attempt
persists to the sync-ready `dictations` table keyed by media target plus
reference window, and "Previous dictations (n)" re-opens a historical
attempt's stored diff. On touch screens, press-and-hold now peeks a line
or the masked dictation band — the gesture the phone hint always claimed
to have, now actually wired, and desktop-only `R`-hotkey copy no longer
renders on phones (#1308, #1352).

## Checkout returns to the app, and sign-out really signs out

Native auth catches up with the server's native-auth v2 (#1433):

- **One-click checkout return.** Every Stripe checkout the app starts —
  prepaid months, auto-renew, credits packages — now lands on a public
  return page that hands you straight back into the app through the new
  `enjoyplayer://checkout/return` deep link, routed to Credits for
  credits packages and Subscription for everything else. Previously the
  payment finished in the browser and the app found out only by polling.
- **Sign-out revokes the server session.** Signing out now calls
  `POST /api/v1/auth/logout` best-effort before clearing local secrets,
  so a refresh token copied off the device dies with the sign-out
  instead of staying valid server-side.
- **Switch accounts at sign-in.** Native PKCE sign-in sends
  `prompt=select_account`, so re-authenticating shows enjoy.bot's
  account picker instead of silently re-binding the previous browser
  session.

## The word book heals itself — or heals on demand

Three sync fixes make vocabulary behave across devices (#1348, #1333,
#1344):

- **Words added on web reach the phone without a cold restart.** The
  periodic sync tick now runs the full vocabulary pull, not just the
  upload queue drain, and the Vocabulary board gains pull-to-refresh
  (plus a header refresh button on desktop) for an on-demand pull that
  never blocks on unrelated media uploads.
- **A drifted word book can be rebuilt on demand.** Settings → Sync
  status gains a manual "Re-pull vocabulary" action that resets both
  sync cursors and pulls the full server word book without mirroring
  remote audio/video/recordings.
- **Upgraded installs re-pull once more, automatically.** The server's
  old `DESC` pagination stranded older web SRS updates outside the
  top-50 window, and the v0.10.x repair had already been consumed
  before the server was fixed. A second one-shot repair clears both
  cursors again on upgrade, so every install re-pulls its word book.

## Craft keeps your edits

Advanced and Express text fields no longer lose in-progress edits when
unrelated state updates arrive mid-typing: external updates wait until
blur, and Re-translate / Regenerate / Use translated text release focus
first so their new value appears immediately, even on touch devices
(#1296).

## Faster, measured

This release carries a systematic pass over the app's hot paths, with
differential measurements recorded in
[docs/perf-measurement.md](https://github.com/baizhiheizi/enjoy_player/blob/main/docs/perf-measurement.md):

- **Cold start** skips redundant preference writes, watches only the
  signed-in user id, and stops blocking on window-manager setup (#1381).
- **The transcript** isolates karaoke underlines from cue chrome,
  selects down to the cue index so a cue change rebuilds two rows
  instead of the viewport, and answers timed-word lookups by binary
  search (#1384, #1385). Craft's rebuild gates decide with allocation-free
  scans — typing states drop from 9.85 to 0.41 ms and the 5 000-character
  maximum from 2 792 ms to 1.08 ms (#1403).
- **Heavy work leaves the UI isolate**: import hashing, large JSON
  encodes, and subtitle parsing move to isolates; ASR audio streams from
  disk instead of materializing ~500 MB of PCM; sync downloads run in
  parallel and the upload drain batches tombstones (#1387, #1388).
- **The data layer** gains its two missing SQLite indexes, streams
  narrow to what their listeners read, and the sidebar's due badge stops
  loading every vocabulary row on cold start (#1386).
- **Vocabulary and subscription** decode their explanation blobs,
  derive their due previews, and construct their date and currency
  formatters once per content or locale instead of per rebuild
  (#1364, #1412, #1438, #1439, #1446, #1457).

## Under the hood: Flutter 3.50.1 / Dart 3.14.0

The toolchain pins Flutter 3.50.1 with Gradle 9.3.1 / AGP 9.1.1, and
~650 files migrate off the deprecated `flutter/material` import to
`material_ui`, clearing 807 deprecation warnings. Linux's WPE WebKit
integration survives the wpe-webkit 2.54 settings-key rename, and the
Android/Linux builds verify the new toolchain end to end (#1454).

## Also in this release

- The dependency set moves forward within the existing constraints —
  flutter_svg 2.5.0, posthog_flutter 5.61.2, drift 2.35.4, sqlite3 3.9.1,
  and the lockfile refresh in between; no dependency is added, removed or
  given a wider constraint, and the ADR-0029 supply-chain pins are
  untouched (#1269, #1373, #1448).
- The release pipelines harden against their 2026-11-24 failure modes: a
  full runner disk reclaims CI-owned caches and requires headroom before
  building, a truncated Gradle distribution is re-downloaded with an
  integrity check, starved-runner compiles retry with backoff, every
  platform job carries an explicit 45-minute bound, and a locked login
  keychain reports as a locked keychain instead of a cryptic Security
  error (#1467). The monolithic CI test job also shards four ways so two
  overlapping PRs cannot swap the shared host (ADR-0105, #1336).
- The local git hooks stop blocking legitimate commits: the pre-commit
  secret scanner reads added lines only and masks just the hex a digest
  context describes, and pre-push slims to a format check (ADR-0104,
  #1317).
- The microphone-capture policy lives in one `MicCaptureSession`, so the
  persisted Settings → Recording choice now applies in Craft too; the
  echo region, dictation session, loop-clip export, transcript upserts,
  AI-call skeletons, credits CTA, date/currency caches and a dozen
  500-line files each collapse to one implementation, with no
  user-visible change (#1283, #1284, #1295, #1301, #1302, #1307, #1316,
  #1331, #1332, #1345, #1347, #1349, #1350, #1357, #1362, #1366, #1367,
  #1368, #1369, #1372, #1379, #1397, #1402, #1411, #1416, #1419, #1423,
  #1428, #1444, #1445, #1455).
