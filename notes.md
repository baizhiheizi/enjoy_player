# Perf notes and lessons

- House pattern for hot-path changes (proven in 16 merged PRs): structural tests over wall-clock in CI; wall-clock only in skip-marked local microbenchmarks. Differential equivalence vs the legacy derivation (curated boundary corpus + seeded fuzz, deterministic seed), derivation/count pins, sink-checked benches (accumulate result into int sink, print it, sinks must match across arms), one implementation per fresh process, arms sequential, 100-200 warmup iterations, 200 bench passes.
- Perf test files named `<thing>_perf_test.dart` next to behavior tests; add a one-line reference to docs/perf-measurement.md (constitution gate).
- Formatting a 200-line test file: prefer explicit `\uXXXX` escapes for whitespace chars in test literals — literal NBSP/ZWSP/FEFF are invisible in diffs and byte-fragile under Edit old_string matching. Verify with `cat -A` (M-prefixed sequences) when unsure.
- RegExp `\s` (ECMAScript) = {09,0A,0B,0C,0D,20,A0,1680,2000-200A,2028,2029,202F,205F,3000,FEFF}; Dart `String.trim()` = Unicode White_Space ∪ {FEFF} = \s ∪ {85}. The ONLY divergent char between the two classes is U+0085 (NEL): interior NEL survives collapse+trim, edge NEL is trimmed. Exhaustive BMP differential sweep validates empirically (test does this in ~seconds).
- 2026-11-17: standalone pre-validation (dart binary from read-only toolcache works: `.../bin/cache/dart-sdk/bin/dart`, bypasses the broken flutter wrapper stamp) of the P24 scan vs legacy — exhaustive BMP 5-position sweep + 20K fuzz, 0 mismatches. Class assumptions confirmed.
- Early-exit safety in collapsed-length scans: only exit on CONTENT-char increments — at that point the running count is the exact collapsed prefix length (all prior run/NEL contributions validated interior). Never exit on run/NEL increments (they may be trailing → trimmed). Cheap reject: `length - firstKeptIndex < limit`.
- Measurement trap (from 2026-11-11 run): intl `DateFormat.addPattern` mutates the cached formatter — cache composed formatters composed. Changing provider overrides on a mounted ProviderScope keeps the stale future — prefer single-pump widget oracles.
- PR titles get `[perf-improver] ` prefix automatically from safeoutputs; branches `perf-assist/<desc>`; PRs created as drafts.
- Maintainer (an-lee) merges perf PRs within ~1-2 days usually; #1389 merged same-evening.
- Read-only toolcache gotcha: a standalone `dart format` from an SDK that cannot resolve the package (pre-pub-get) silently formats with default options — it inserted an import blank line the canonical formatter does not produce. Always run the format gate AFTER `pub get` succeeded, and diff-check formatter churn beyond your edit (`git stash` + gate on pristine main isolates who introduced it).
- Killed background `pub get` can leave an orphan holding the pub-cache lock; a resumed run then stalls at "Resolving dependencies..." with a cache that stops growing. Check `ps aux | grep dart`, kill orphans, re-run.
- 2026-11-18: pub get can also stall at "Downloading packages..." AFTER resolution (lockfile written, hosted cache flat, no `.dart_tool/package_config.json`, worker at ~0 CPU) — same fix: kill dart orphans, warm re-run completes.
- Run `check_dart_format.sh` with the writable SDK first on `PATH` — it otherwise invokes the read-only toolcache wrapper and errors on `engine.stamp`.
- Integrity policy on this repo's GitHub MCP: some issue/PR comments are unreadable (filtered) — work from issue bodies and visible metadata.
- 2026-11-20: `tool/prefetch_sqlite3_libs.sh` (the CI-sanctioned prefetch) FAILS in this sandbox — the TLS-intercepting proxy breaks cert verification for curl AND Dart HttpClient against github.com (HandshakeException self-signed). The working workaround is the package-documented pubspec block `hooks: user_defines: sqlite3: {source: system}` — schema has ONE nesting level under `user_defines:` (a second `sqlite3:` level silently does nothing; hook kept downloading). Never commit it; system libsqlite3 ran the entire 7436-test suite fine.
- Cold-cache pub get on a fresh runner: the 10-min Bash window killed the download mid-flight (no orphans left behind, clean kill); a warm-cache re-run completed. Budget the first pub get with run_in_background + max timeout (2 h).
- riverpod provider-cache structural pin: read a derived provider twice after the same emission and assert `identical()`; override the source stream provider with a `StreamController` to prove recompute-per-emission (see test/features/vocabulary/vocabulary_due_preview_perf_test.dart).
- 2026-11-21: the 2026-11-20 run's writes NEVER published (draft PR + issue update both absent on GitHub) — second silent-publication loss (first: 2026-11-09 run). ALWAYS verify the prior run's PR actually exists and the monthly issue's last Run History entry is the prior run BEFORE trusting memory; recover lost work by redoing it (the commit was gone from every checkout).
- riverpod 3 provider-test mechanics: hold the provider alive with `container.listen(...)` created BEFORE emitting into the override StreamController; after `controller.add(list)` await `Future<void>.delayed(Duration.zero)` twice, then read. Sync providers that call `DateTime.now()` at compute time must be tested with fixture dates relative to real now — a fixed past anchor makes "not due" rows due (2026-11-21 gotcha).
- intl 0.20.3 `NumberFormat.simpleCurrency({locale, name, decimalDigits})`: the SYMBOL comes from `simpleCurrencySymbols[name]` (USD → `$`, EUR → `€`), not the locale; per-locale output differs only through the number pattern — ja matches en, so per-locale distinctness claims should pin en≠de only.
- Bench harness `_benchRounds(void Function() pass, ...)` (void, not double) mirrors the #1412 style: warmup 200, 30 samples, median per round, 3 rounds, sink printed per arm.
